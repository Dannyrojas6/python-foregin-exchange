# pyfx

一个简洁、快速的命令行汇率转换工具，支持实时汇率查询、历史数据分析和趋势追踪。

## ✨ 功能

- **快速转换**：支持 300+ 种法定货币与加密货币实时转换
- **趋势分析**：查看汇率历史走势，支持导出 CSV 数据
- **美观输出**：使用 Rich 库打造精致表格与彩色展示
- **批量转换**：一次性查询多个货币对，省时高效
- **反向计算**：轻松计算「需要多少源货币才能换到目标金额」
- **历史查询**：支持任意指定日期的历史汇率查询
- **计算器模式**：交互式汇率计算器，随时随地换算

## 📦 安装

### 使用uv

```bash
# 克隆仓库
git clone https://github.com/Dannyrojas6/python-foregin-exchange.git
cd pyfx

# 安装依赖
uv sync

# 运行
uv run pyfx --help
```
